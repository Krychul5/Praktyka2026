# Praktyki zawodowe – projekt strony internetowej

Witaj w repozytorium z zadaniami na praktyki. W ciągu 20 dni zbudujesz od podstaw stronę internetową przykładowej albo rzeczywistej firmy. Nie musisz znać wszystkich technologii przed rozpoczęciem. Każde zadanie zawiera wyjaśnienia, przykłady i checklistę.

## Co wykonasz

Gotowy projekt będzie zawierał:

- responsywną stronę główną, ofertę, galerię, opis firmy i kontakt;
- interakcje wykonane w JavaScript;
- formularz kontaktowy;
- bazę danych MySQL;
- prosty panel administracyjny w PHP;
- instrukcję instalacji i dokumentację projektu.

Domyślne technologie: **HTML5, CSS3, JavaScript, Bootstrap, PHP, MySQL i Git**.

## Zasada samodzielności

Możesz korzystać z dokumentacji, wyszukiwarki i podpowiedzi opiekuna. Nie kopiuj całych gotowych projektów. Jeśli wykorzystujesz fragment kodu z zewnętrznego źródła:

1. przeczytaj go i upewnij się, że rozumiesz każdą linię;
2. dopasuj go do własnego projektu;
3. zapisz źródło w dokumentacji;
4. potraf wyjaśnić opiekunowi sposób działania.

Jeśli utkniesz, najpierw sprawdź komunikat błędu, konsolę przeglądarki i dokumentację. Następnie zapisz: co próbujesz zrobić, co się wydarzyło, czego oczekiwałeś oraz czego już próbowałeś. Z takim opisem poproś opiekuna o pomoc.

## Co oddajesz każdego dnia

Każdy dzień powinien zakończyć się:

- działającą wersją wykonanej części;
- kilkoma niewielkimi commitami Git;
- wypchniętą gałęzią roboczą;
- Pull Requestem z opisem wykonanej pracy;
- informacją, jak opiekun może sprawdzić zmianę;
- zrzutem ekranu, jeśli zmienił się wygląd strony.

## Najważniejsze zasady

- Nie umieszczaj w repozytorium haseł, kluczy, danych osobowych ani prawdziwych wiadomości klientów.
- Nie pracuj bezpośrednio na gałęzi `main`.
- Nie ignoruj błędów w konsoli przeglądarki i komunikatów PHP.
- Nie usuwaj działających funkcji bez uzgodnienia.
- Regularnie sprawdzaj stronę na telefonie lub w trybie urządzeń mobilnych.
- Pytaj, gdy wymaganie jest niejasne. Dobre pytanie jest częścią pracy informatyka.

## Kiedy projekt jest ukończony

Projekt jest gotowy, gdy wszystkie obowiązkowe checklisty są zaznaczone, opiekun zaakceptował cztery punkty kontrolne, projekt można uruchomić według README, a Ty potrafisz samodzielnie pokazać i wyjaśnić jego działanie.
